# Five logomark directions for a consumer health product

Concept by [Vipin Sao](https://contra.com/vipin_sao_z8eilxkm): five logomark directions for a healthcare product people trust with their medical records and their money.

Live page: https://vipinsao.github.io/health-logomark-directions/

- `index.html`: the page (no build step)
- `marks.js`: the five marks as SVG paths, the single source for every render on the page
- `favicon.svg`, `og.jpg`: tab icon and link preview

Self-initiated concept made in response to an open brief. Not a commissioned client project.
